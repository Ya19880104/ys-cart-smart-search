# YS CART 智慧搜尋

YS CART 站內智慧搜尋 add-on（對標 Searchanise）：即搜即得、混合式熱門關鍵字、完整搜尋分析。

## 功能

- **搜尋 Bar 與 Icon 彈窗**：`[ys_ss_search]`（行內搜尋框）、`[ys_ss_search_icon]`（圖示 → 全屏彈窗）；可選「接管核心搜尋短代碼」一鍵升級既有版位。
- **熱門搜尋建議**：點擊搜尋框即顯示熱門關鍵字 chips —— **手動置頂 + 自動統計混合**，數量可設（預設 8）；另有純瀏覽器端「最近搜尋」。
- **即搜即得分組結果**：商品（縮圖／價格／SKU 可開關）、分類（含商品數）、文章／頁面（可選 post types、縮圖、摘要字數）——各組筆數與順序皆可設定；關鍵字高亮、鍵盤導航、零結果 fallback。
- **搜尋分析報表**：期間篩選（今日／7／30／90 天／自訂）、KPI（總次數／獨立關鍵字／零結果率）、每日趨勢、熱門關鍵字排行（一鍵轉手動關鍵字）、**零結果關鍵字排行（商機清單）**、CSV 匯出。
- **資料保留**：原始紀錄保留天數可設（預設 180 天），每日自動清理；獨立資料表（3 張 `ys_ss_*`），分析為旁路、**絕不影響搜尋與 YS CART 運作**。

## 需求

- WordPress 6.0+／PHP 8.1+
- **YS CART** 外掛（本外掛依附核心：選單、設計系統、REST namespace、每日排程皆掛核心）

## 隱私

- 不記錄原始 IP／UA；訪客識別為「當日鹽」雜湊（16 字），僅能做同日去重、無法跨日追蹤。
- 「最近搜尋」只存在訪客瀏覽器（localStorage），不上傳伺服器。
- 公開紀錄端點有限流與長度限制。
